# v0.6 feature combination validation — 2026-11-01

The v0.6 candidate is **not yet an established strength improvement**. Do not merge the combined implementation with every heuristic enabled: it lost -45.42 ±39.24 Elo versus historical v0.5.

## Experiment

- Candidate engine code: `0b616a0e05138e2ab8ae32010be818aa533989cc`; exact UCI option sets recorded in each `metadata.json`.
- Historical v0.5 baseline: `9189218c76bee69c08a7e29dad12650ada2d1b13`.
- [Full 4-candidate GitHub Actions run 41304412246](https://github.com/LorFerSilve/Bitboard-Chess-Engine/actions/runs/41304412246).
- 200 games = 100 color-reversed opening pairs per candidate, extended.epd, new shuffle seed `20261102`, 3+0.03, 16 MB hash, portable Linux Release+LTO; each candidate set `All Heuristics=false` and explicitly enabled named features.

**Interpretation:** At this sample size, none of these four combinations has established a positive Elo gain versus v0.5. The largest point estimate is +5.21 Elo, far smaller than its reported uncertainty. The first-stage +37.79 Elo point estimate for King Pressure alone did not generalize to a new 200-game shuffle; selecting parameters on one batch is prone to overfitting and multiple-comparison bias.

**Next experiment:** omit the inconsistent King Pressure term entirely and test Knight Forks, Clustered TT and their combination, alongside an all-off control, on another seed (20261103). These tests also require confirmation before any release claim. If no robust winning candidate emerges, retain v0.5 as the official strongest release; the v0.6 PR may be preserved for experimental development only.
